# Сервисы для разработки

Ниже зафиксированы временные параметры подключения для текущего этапа разработки. После переноса в продакшен значения будут заменены.
Секреты в этом файле замаскированы для безопасного хранения в GitHub.
Локальные реальные значения хранятся в `doc/Сервисы.local.md` (файл не отслеживается Git).

## S3

- Имя бакета: `<bucket-name>`

## PostgreSQL

- Внутренний URL: `postgresql://<user>:<password>@<internal-host>:5432/<db>`
- Внешний URL: `postgresql://<user>:<password>@<external-host>:5432/<db>`

## Redis

- Внутренний URL: `redis://<user>:<password>@<internal-host>:6379`
- Внешний URL: `redis://<user>:<password>@<external-host>:6379`
