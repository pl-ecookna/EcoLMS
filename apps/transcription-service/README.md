# Transcription service

Локальный сервис транскрибации на базе `faster-whisper`.

Планируемая зона ответственности:

- прием аудиофайла или ссылки на файл;
- загрузка исходников из S3-compatible storage;
- ffmpeg-нормализация в `16kHz mono wav`;
- запуск Whisper;
- возврат текста, сегментов и метаданных выполнения;
- изоляция ресурсоемкой транскрибации от worker.
