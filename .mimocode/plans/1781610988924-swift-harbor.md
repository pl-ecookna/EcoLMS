# План: кнопка запуска + cleanup при ошибке загрузки

## Задачи

### 1. Кнопка «Запустить обработку» в MeetingDetailView

**Файл:** `apps/web/src/components/meetings-client.tsx`

Добавить кнопку в шапку детального вида (строка 2279, рядом с «К списку»). Видна когда:
- `meeting.status === "uploaded"` И `meeting.sourceFile?.uploadStatus === "completed"`

Вызывает `startMeeting(meetingId)`, обновляет meeting state.

### 2. Cleanup встречи при ошибке загрузки файла

**Файл:** `apps/web/src/components/meetings-client.tsx` — `handleCreateMeeting`

Сейчас если `uploadMeetingFile` падает, `catch` показывает ошибку, но карточка встречи остаётся в БД со статусом `draft`.

Добавить: если загрузка файла упала — вызвать `deleteMeeting(created.id)` в catch-блоке.

```
} catch (error) {
  // cleanup: удалить карточку если файл не загрузился
  if (created?.id) {
    await deleteMeeting(created.id).catch(() => undefined)
  }
  ...
}
```

Для этого нужно вынести `created` за scope try/catch или добавить в catch проверку.

## Верификация

1. `pnpm --filter web exec tsc --noEmit`
2. При ошибке загрузки — встреча не остаётся в списке
3. Встреча в статусе `uploaded` + файл `completed` — кнопка «Запустить обработку» видна и работает
