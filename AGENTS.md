# Инструкции для Codex в этом проекте

- В чате с пользователем всегда отвечай на русском языке.
- При создании и доработке интерфейсов используй только компоненты `shadcn/ui`.

## Dokploy

- Для работы с Dokploy в первую очередь используй MCP-сервер `dokploy_entechai`, если он доступен в текущей сессии.
- Если MCP недоступен или не покрывает нужное действие, используй `Dokploy CLI` как fallback.
- Целевой сервер Dokploy для этого проекта: `https://srv.entechai.ru/`
- Целевой проект в Dokploy: `EcoLMS`
- Не запрашивай у пользователя URL/API-key повторно, если они уже есть в локальной конфигурации Codex или CLI.
- Не сохраняй API-key в коде проекта, `.env`, документации репозитория или коммитах.
- Для CLI предпочитай уже настроенную локальную авторизацию. Если авторизация потеряна, используй локальные переменные окружения или сохранённый login, а не проси пользователя заново вводить ключ без необходимости.
- При диагностике деплоя сначала проверяй:
  - deployments сервиса
  - runtime logs
  - effective environment variables
  - health/API-ответ приложения после деплоя
- При работе с Dokploy старайся сначала использовать наименее рискованные действия:
  - просмотр логов и статусов
  - проверка env
  - redeploy конкретного сервиса
  - и только потом более широкие действия
